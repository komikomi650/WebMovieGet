# かんたん WEB動画保存 (WebMovieGet)

本ツールは、WEB上の動画URLを貼り付けるだけで、誰でも簡単に動画をパソコンへ保存（ダウンロード）できるWindows用デスクトップツールです。

別のパソコンで本ツールを使用する場合は、以下の手順に従って環境設定を行ってください。

---

## 必要な動作環境・ツール

本ツールを動かすには、以下の3つの環境設定が必要です。

1. **Python（パイソン）のインストール** (プログラミングを実行するシステム)
2. **`yt-dlp` ライブラリのインストール** (動画をダウンロードするためのプログラム)
3. **FFmpeg（エフエフエムペグ）の設置** (高画質な映像と音声を綺麗に結合するためのツール)

---

## 環境設定手順（セットアップ方法）

セットアップには、**「方法A：自動で設定する（推奨・かんたん）」** と、**「方法B：手動で設定する」** の2種類の方法があります。通常は「方法A」をご利用ください。

---

### 【方法A】自動で設定する（推奨・かんたん）

PC操作に自信がない方でも、最も簡単に準備ができる方法です。

1. **Python のインストール**
   - Pythonの公式サイト（ https://www.python.org/downloads/ ）からインストーラーをダウンロードし、起動します。
   - **【最重要】** 画面の下部にある **「Add python.exe to PATH」** というチェックボックスに**必ずチェックを入れてから**インストールを実行してください。
2. **「簡単初期設定.bat」の実行**
   - 本ツールと同じフォルダにある **「簡単初期設定.bat」** をダブルクリックして起動します。
   - 画面の案内に従って「Y」を入力すると、必要なプログラム（`yt-dlp`）の導入と、高画質化ツール（`FFmpeg`）のダウンロード・配置がすべて自動で行われます。
   - 画面に「初期設定がすべて完了しました！」と表示されたら、キーボードの何かキーを押して画面を閉じます。これで準備は完了です。

---

### 【方法B】手動で設定する

各パーツを自分でダウンロードして手動で配置する方法です。

#### 1. Python のインストール
- 方法Aと同様に、Python公式サイトから「Add python.exe to PATH」にチェックを入れてインストールします。

#### 2. yt-dlp のインストール
- コマンドプロンプト（黒い画面）を起動し、以下のコマンドを実行します：
  ```cmd
  pip install yt-dlp
  ```

#### 3. FFmpeg のダウンロードと配置
- FFmpegの配布サイト（ https://www.gyan.dev/ffmpeg/builds/ ）から「`ffmpeg-release-essentials.zip`」等のパッケージをダウンロードし、解凍します。
- 解凍したフォルダの `bin` フォルダ内にある **`ffmpeg.exe`** と **`ffprobe.exe`** をコピーし、本ツールのプログラム（`YoutubeMovieGet.pyw`）と**同じフォルダの中に直接貼り付けて配置**してください。

---

## 起動方法

1. `YoutubeMovieGet` フォルダを開きます。
2. **`run.bat`** ファイルをダブルクリックします。
3. アプリケーション画面（「かんたん YouTube動画保存」）が自動で立ち上がります。

---

## トラブルシューティング（動かない・保存できない場合）

### Q. 保存ボタンを押してもダウンロードに失敗する
YouTubeは仕様が頻繁に変更されます。ダウンロードに失敗するようになった場合は、`yt-dlp` が古くなっている可能性があります。
コマンドプロンプトを開き、以下のコマンドを実行して最新版にアップデートしてください。
```cmd
pip install -U yt-dlp
```

### Q. 「FFmpegが見つかりません」というエラーが出る、または保存された動画の画質が粗い
高画質動画と音声の結合を行う「FFmpeg」が正しく認識されていません。
本ツールのフォルダ（`YoutubeMovieGet`）の中に、`ffmpeg.exe` と `ffprobe.exe` が正しく配置されているか確認してください。

### Q. 「Sign in to confirm you’re not a bot」というエラーが出る
YouTube側のBot認証（ロボット判定）に引っかかっている状態です。
本ツールでは自動的に**スマホ公式アプリ通信（iOS/Android/mweb）**に切り替えてアクセスすることで、Bot認証を自動回避する設計になっています。
もしこのエラーが出た場合は、`yt-dlp` のバージョンが古い可能性がありますので、上記「保存ボタンを押してもダウンロードに失敗する」と同様に `pip install -U yt-dlp` を実行して最新化してください。
